# artistgrid-downloader
A Python script that downloads the most famous songs form an [ArtistGrid](https://artistgrid.cx) section

## Setup
1. Download Python (newer then 3.9)
2. Run the script

## Usage
Options:
`--tab` (best, main, grails, special, recent, …), `--limit`, `--marker`, `--era`, `--full-only`, `--include-worst`, `--out`, `--dry-run`, `--delay`, `--retries`
Files are downloaded to "downloads/artist/tab"
